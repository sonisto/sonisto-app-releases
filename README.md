# Sonisto releases

Release downloads for Sonisto, a plugin manager for Mac and Windows. It scans your computer and lists every VST, AU and AAX plugin you have installed in one library, sorted by brand, with each plugin's version and format, and shows which plugins have a newer version.

- Download and details: https://sonisto.com/desktop-app/
- Plugin managers compared: https://sonisto.com/best-plugin-managers/
- Guides: https://sonisto.com/guides/
